Checklist hari-H ujian

  • Bagi peserta menjadi beberapa sesi/ruang; jangan semua siswa menekan Mulai pada detik yang sama.
  • Siswa login dan membuka daftar ujian sebelum jam mulai, lalu menunggu aba-aba token dari pengawas.
  • Rilis token baru tiap sesi dengan tombol Acak & Rilis Token Baru.
  • Jika siswa terputus/browser mati, pilih Reset agar bisa mulai ulang, atau biarkan: ia bisa login lagi dan melanjutkan dengan sisa waktu yang sama.
  • Jawaban siswa yang waktunya habis tetapi tidak sempat mengumpulkan akan disimpan otomatis oleh server (trigger tiap 5 menit).
  • Kunci jawaban tidak pernah dikirim ke perangkat siswa; penilaian dilakukan di server.

Tambah User Baru

Jika NISN/Username diubah, riwayat ujian siswa ini ikut dipindahkan. Siswa harus login ulang dengan username baru.

Import User Massal (CSV)

Tambah Soal Manual

Contoh: x^{2} → x², \frac{3}{4} → pecahan ¾, \sqrt{16} → akar. Berlaku di pertanyaan maupun opsi jawaban. Tekan Tab untuk lompat keluar dari kurung kurawal.

Import Paket Soal (CSV Multi-Tipe + Gambar)

Kolom CSV: Tipe,Soal,Gambar,Soal2,OpsiA_P1,OpsiB_P2,OpsiC_P3,OpsiD,OpsiE,Kunci

Soal = pertanyaan sebelum gambar, Soal2 = pertanyaan sesudah gambar (opsional). Rumus: x^{2}, \frac{3}{4}, \sqrt{16}.
